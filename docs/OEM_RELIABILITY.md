# 后台可靠性

## 原则
- 不为计时创建永久前台服务；Session 恢复（锚点 + reconcile）是最终兜底。
- 不自动修改任何系统设置；厂商指引只做导航与文字说明。

## 用户指引（Guard 向导内展示）
- 若结束提醒延后/丢失：系统设置 → 电池/后台限制，将 FocusFlow 设为不优化/允许后台。
- 小米/华为/OPPO/vivo：建议在最近任务锁定 FocusFlow、允许自启动；具体入口因 ROM 版本而异。
- EXTREME 屏幕固定期间系统会暂停部分后台行为，属预期。

## 待真机验证
Restricted/Optimized 状态检测、各厂商自启动与锁屏行为、开机恢复与提醒到达率；验证后在本文档逐机记录。
