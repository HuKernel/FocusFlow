# 产品

FocusFlow 将任务、可靠计时、Session 进度、跨设备同步与 Focus Guard 结合。
第一阶段 Android Phone/Tablet，第二阶段 Desktop。原型定义视觉方向，不代表现有功能。

优先级：可靠计时 → Session 聚合正确 → 离线同步 → 自适应 → Focus Guard → 动效与声音。
当前 M2/0.3.0 已实现离线任务规划、Today、项目和标签管理，以及普通专注；页面不使用虚构任务、同步成功或权限已启用状态。
任务默认安排到本地今天，支持明天、未安排或指定日期；Today 显示今日任务、今日专注与连续专注天数。勾选任务完成不生成 FocusSession。
任务“开始专注”进入倒计时/正计时设置，支持暂停/继续/取消、完成总结与休息。进程重开恢复会话，COMPLETED 时长累计到任务。Android 可选结束通知，不影响未授权时正常计时。
下一阶段 M3 动效/声音/触感；M5 账号与同步，M8 Strict/Extreme。尚未提供任务日程提醒、重复任务或编辑草稿进程死亡恢复。
完整需求以仓库 DOCX 与 AGENTS.md 为准。
