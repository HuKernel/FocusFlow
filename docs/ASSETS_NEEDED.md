# 素材待办

当前 Android 端使用运行时生成的正弦衰减测试音（cacheDir WAV，见 AndroidFeedback.kt），仅作占位反馈，不涉及第三方版权。

## 需要的原创 / royalty-free 素材
- 8 个 SoundEvent 的正式短音效：focus_start、focus_pause、focus_resume、focus_complete、task_complete、break_start、achievement、error（风格：calm/soft/premium，长度 ≤ 0.7s，OGG/Opus）。
- 白噪音音源（雨声/风声/咖啡馆等，循环无缝），需明确许可证与来源；交付前记录授权范围、作者、来源及必要 attribution。
- 交付时替换 AndroidSoundController 的生成逻辑，业务侧仅改 SOUND_EVENTS 映射，不改接口。
- 用户提供的原型仅用于设计参考，原型中的缺字图标不应照抄。
